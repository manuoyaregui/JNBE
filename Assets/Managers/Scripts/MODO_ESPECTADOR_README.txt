===============================================
   MODO ESPECTADOR - SOLO PARA EDITOR
===============================================

DESCRIPCIÓN:
Este script permite volar libremente por la escena durante las pruebas
en el editor de Unity. Es completamente seguro ya que NO se incluye
en builds finales del juego.

CÓMO USAR:
----------
1. Abre cualquier escena en Unity
2. En la jerarquía, selecciona el GameManager
3. En el Inspector, haz clic en "Add Component"
4. Busca y agrega "EditorSpectatorMode"
5. ¡Listo! Ahora puedes usar el modo espectador en Play Mode

CONTROLES:
----------
- F12: Activar/Desactivar modo espectador
- WASD: Mover la cámara (W=adelante, S=atrás, A=izquierda, D=derecha)
- Q/E: Bajar/Subir verticalmente
- Shift: Velocidad rápida (multiplica la velocidad)
- Mouse: Rotar la cámara
- Escape: Liberar el cursor
- Click Izquierdo: Volver a bloquear el cursor

AJUSTES:
--------
En el Inspector puedes ajustar:
- Fly Speed: Velocidad normal (default: 10)
- Fast Fly Speed: Velocidad con Shift (default: 50)
- Mouse Sensitivity: Sensibilidad del mouse (default: 2)

IMPORTANTE:
-----------
- Este script SOLO funciona en el Editor
- NO se incluye en builds finales
- Útil para pruebas, debugging y navegación rápida de la escena
- No afecta el rendimiento en builds
